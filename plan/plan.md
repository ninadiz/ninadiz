# План: уменьшить главный JS-бандл

## Проблема

`npm run build` выдаёт предупреждение: `dist/assets/index-*.js` весит 733 kB (234 kB в gzip), больше лимита Vite в 500 kB. Весь код и все библиотеки лежат в одном чанке, потому что в проекте нет code-splitting. Главная страница загружает то, что нужно только страницам кейсов.

## Что, скорее всего, даёт вес (оценка, не замеры)

- `react-dom`: фиксированная база React.
- `@xyflow/react` (+ `d3-*`): интерактивные диаграммы `DesignerNetworkDiagram` и `RefillingProcessFlow`. Вероятно, самый крупный кусок.
- `react-markdown` + `rehype-raw`: тянут весь unified-стек (remark, rehype, parse5, micromark).
- `react-router`: заметный кусок.
- `js-yaml`, `lucide-react`: небольшие.

## Шаги

1. **Измерить.** Подключить `rollup-plugin-visualizer` (только на время анализа), собрать и посмотреть точную разбивку по модулям. Убрать плагин после анализа или оставить за флагом.
2. **Lazy-загрузка страниц.** В `src/App.jsx` обернуть `CaseStudy` (и при необходимости `Contact`, `Portfolio`) в `React.lazy` + `import()`, добавить `<Suspense>` с простым fallback.
3. **Lazy-загрузка диаграмм.** Компоненты из `src/lib/embeds.js` (`DesignerNetworkDiagram`, `RefillingProcessFlow`) подключать через `React.lazy`, чтобы `@xyflow/react` грузился только в кейсах, где диаграмма реально используется.
4. **Пересобрать и сравнить.** `npm run build`, сверить размеры чанков до и после. Главный чанк должен упасть ниже 500 kB, а `@xyflow` и markdown-стек уйти в отдельные чанки.
5. **Проверить в браузере.**
   - Главная `/` открывается и не грузит чанки кейсов.
   - Кейс `/cases/<slug>` открывается, диаграммы рендерятся.
   - Прямой заход по ссылке на кейс работает (prerendered `index.html`).
   - Нет ошибок в консоли, нет заметного мигания fallback.
6. **Проверить `scripts/prerender-meta.mjs`.** Скрипт копирует `dist/index.html`. Убедиться, что он по-прежнему работает с новой структурой чанков и мета-теги кейсов на месте.

## Риски и заметки

- Lazy-загрузка добавляет сетевой запрос при переходе на кейс. Для личного портфолио это приемлемо, при желании можно сделать prefetch по hover на ссылку.
- Если после lazy-загрузки главный чанк всё ещё больше 500 kB, добавить `build.rollupOptions.output.manualChunks` для вынесения `react`/`react-dom`/`react-router` в отдельный vendor-чанк.
- Альтернатива: поднять `build.chunkSizeWarningLimit`. Это убирает предупреждение, но не уменьшает размер, поэтому как основное решение не рассматривается.
- Текущие 234 kB в gzip для портфолио терпимы, так что задача не срочная.
