# Favicons

Everything for the site icon. All files are served from the site root (`/favicon.ico`, `/favicon.svg`…) by `vite.config.js`, and linked from `index.html`.

| File | Used for |
|---|---|
| `favicon.svg` | Modern browsers |
| `favicon-32x32.png`, `favicon-16x16.png` | Fallback PNG sizes |
| `favicon.ico` | Legacy browsers |
| `apple-touch-icon.png` | iOS home screen |
